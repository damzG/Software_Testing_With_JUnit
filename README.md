# Software Testing with JUnit

## Overview

This repository documents my learning and practical work in **Software Testing and Verification** as part of the Software Engineering module.

The focus is on understanding how to test Java classes and methods using **JUnit**, write effective test cases, and evaluate software quality through different testing techniques and code coverage measurements.

## Learning Objectives

- Understand the principles of **software verification and validation**.
- Learn how to write and execute unit tests using JUnit.
- Understand the difference between **black-box and white-box testing**.
- Design test cases based on software requirements and expected behaviour.
- Use JUnit assertions to check whether methods produce the expected results.
- Understand how to test normal, boundary, and invalid input values.
- Interpret test results and identify failures in software implementations.
- Explore code coverage and understand what testing coverage can tell us about a program.

## Topics Covered

### 1. Unit Testing with JUnit
- Creating and organising JUnit test classes.
- Testing individual Java methods.
- Using assertions such as `assertEquals()`, `assertTrue()`, `assertFalse()` and `assertThrows()`.
- Understanding successful and failed test results.

### 2. Black-Box Testing
Testing software based on its requirements and expected behaviour, without needing to know how the internal code is implemented.

Techniques include:
- Equivalence partitioning.
- Boundary value analysis.
- Testing valid and invalid inputs.

### 3. White-Box Testing
Testing software by examining its internal code structure and logic.

Topics include:
- Statement coverage.
- Branch coverage.
- Condition coverage.
- Testing conditional statements and execution paths.

### 4. Verification and Validation
Understanding how software is checked to ensure it meets its requirements and behaves as expected.

### 5. Code Coverage
Learning how to interpret coverage reports and understand how much of the source code is exercised by tests.

Coverage concepts include:
- Line coverage.
- Instruction coverage.
- Branch coverage.
